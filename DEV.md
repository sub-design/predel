# ПРЕДЕЛ — как устроен код

Сборки нет: `index.html` (разметка и стили) подключает обычные скрипты из `js/` по порядку. Все они делят одну глобальную область видимости, поэтому порядок подключения важен: код верхнего уровня может вызывать только то, что объявлено в этом же или более раннем файле.

| Файл | Что внутри |
|---|---|
| `js/core.js` | константы, общие помощники, рендерер, процедурные текстуры |
| `js/maps.js` | постройка 10 карт, графы навигации ботов, таблица карт, `loadMap` |
| `js/physics.js` | столкновения с коробками и движение |
| `js/fx.js` | таблица оружия, визуальные эффекты |
| `js/audio.js` | звуки и музыкальный секвенсор (своя тема у каждой карты) |
| `js/entities.js` | игроки и боты, характеры ботов, их реплики |
| `js/net.js` | настройки, таблицы режимов, сеть хоста и гостя, переподключение, сглаживание |
| `js/modes.js` | Король горы, Захват флага, Последний выживший |
| `js/combat.js` | появление, стрельба, снаряды, урон, фраги |
| `js/ai.js` | бонусы и поведение ботов |
| `js/player.js` | управление игроком, оружие в руках |
| `js/hud.js` | HUD, таблица счёта, статистика после матча |
| `js/game.js` | ход матча, меню, лобби, настройки, чат |
| `js/main.js` | главный цикл |

## Проверки

Запустить локально (из папки проекта):

```bash
python3 -m http.server 8124
```

- **Синтаксис** всех файлов:

  ```bash
  for f in js/*.js tools/*.js; do node --check "$f" || echo "FAIL $f"; done
  ```

- **Быстрая проверка** (`tools/smoke.js`): открыть `http://localhost:8124/?smoke`. Примерно за 5 секунд:
  - проходит аудит навигации;
  - каждый из 8 режимов на каждой из 10 карт с ботами;
  - экран итогов со статистикой;
  - все музыкальные темы.

  Случайность в тесте фиксирована, результат на экране: PASS или FAIL со списком проблем.
- **Аудит навигации** отдельно (`tools/nav-audit.js`): открыть `?navaudit`. Бот проходит каждое ребро графа на каждой карте и должен дойти. После правки карты или графа — сюда.

Сеть так не проверить: для неё нужны два окна (хост и гость, например через `?host=КОД` и `?join=КОД`).

## Выкладка

GitHub Pages кеширует файлы на 10 минут. Поэтому перед коммитом с изменениями в `js/` нужно обновить метку версии в тегах скриптов:

```bash
sh tools/stamp.sh
```

Дальше `git push` в `main`, и через минуту изменения на https://sub-design.github.io/predel/.

Пароль ретранслятора (TURN) в репозиторий не попадает: он передаётся в ссылке-приглашении после `#` и хранится только в браузере.
